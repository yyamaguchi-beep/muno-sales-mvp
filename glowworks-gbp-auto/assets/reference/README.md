# 実際の店舗写真 (任意)

ここに GLOW WORKS 生野 の実際の室内写真 (jpg / png / webp) を置くと、`IMAGE_MODE=auto` (既定) または `edit` のとき
画像編集モードで「実際の空間をベースにした利用シーン」を生成します。

- 写真は日付ごとにローテーションで1枚選ばれます
- 利用者・スタッフの顔が写った写真は置かないでください (本人の同意なく生成AIへ送信しないため)
- このフォルダの画像は `.gitignore` で Git 管理外です。GitHub Actions で使う場合は、
  リポジトリに含めてよいか確認したうえで `.gitignore` の該当行を外してコミットしてください
- 生成画像には既定で「※画像はイメージです」が入ります (実在施設写真との誤認防止)
